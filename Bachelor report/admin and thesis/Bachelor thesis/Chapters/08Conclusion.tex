
\textit{This chapter summarizes and reflects on the project.}


The goal of the project was to evaluate if new visualization methods and features that are currently not in use at the norwegian coastal administration could bring value to them if implemented. The final software allows for multiple visualization modes to be filtered and interacted with. 

Work on the project was done in iterations, following agile methodology. Weekly sprints were completed, with constant customer communication throughout the project through slack. React and choice of libraries like deck.gl, lead to a modular design of components for user interface, with deck.gl and maplibre providing hardware accelerated performance for visualization and map interaction. 

The project demonstrates that third party tools can be used to test out new concepts, before full production is done on features that might not bring value to the customer, eliminating more risk than without evaluating if such features are to be created. Extensions to the current software can be adding actual data of AIS messages and vessels, or adding new data types and visualization methods.
